# AIDO-MOAT-MEJIP 1.0 — GitHub MVP Release Candidate

**Release candidate date:** 2026-08-28  
**Purpose:** public proof layer / minimum executable reproducibility surface.

This package exposes the smallest code surface needed to inspect the manuscript-facing adjudication behavior without publishing private datasets, unpublished adapters, or post-1 experimental branches.

## Included

- dependency-aware evidence collapse;
- explicit `SURVIVES`, `WEAK`, `FALSIFIED`, and `UNDERDETERMINED` behavior;
- decisive contradiction retention;
- frozen MC1215 held-out RNA challenge rule;
- recovered Practical-1 Stage-11 ordered admission predicate;
- Practical-2 S9 ledger integrity audit;
- simple same-task comparator baselines;
- machine-readable frozen-result registry with internal consistency checks;
- deterministic self-tests.

## Scientific boundary

The code demonstrates evidence-entitlement and adjudication contracts. It does **not** establish causal truth, biological superiority, treatment utility, or unique patient mechanisms. `MODEL_READY` is an evaluability state; `SURVIVES` is bounded compatibility; `FALSIFIED` is contradiction under a frozen challenge rule; `UNDERDETERMINED` is insufficient entitlement rather than computational failure.

## Data and reproducibility

No private data are bundled. Frozen result counts are provided only as a verification registry. Exact source/resource hashes and machine-readable manuscript artifacts should be deposited only after repository/release authorization. No DOI is asserted in this release candidate.
